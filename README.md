# The Last Light of Mount Ember

The Lantern on Mount Ember has gone dark, and the Hushwing drinks its fire. Captain Ilse Varn's Lamplighter expedition
climbed after it and never came back. Now it's Wren's turn.

A blocky 3D parkour climb in a single HTML file (three.js). Climb from Lowmeadow through the Sunscar Badlands, the
Undermine, the Frostrise, Emberdeep and the Shattered Sky. Fight the Hushwing on the summit with Varn's bow, free the
stolen embers and light the Lantern again. Then glide home on the wingsail through the signal rings.

**Play:** open the GitHub Pages link for this repo, or open `index.html` in a browser.

## Controls

| Key | Action |
| --- | --- |
| W A S D | Move |
| Space | Jump · in mid-air with the wingsail: open it |
| Shift | Sprint |
| Mouse | Camera / steer in flight |
| Left mouse / F | Draw and shoot the bow (summit fight) |
| Q | Lock on (summit fight) |
| E | Use |
| Backspace | Back to the last checkpoint (in flight: re-fly from the summit) |
| R | Quick restart (same course) |
| M | Mute |
| Esc / P | Pause |

Type or roll a seed on the start screen for a procedurally generated course (SHORT / CLASSIC / MARATHON length).
